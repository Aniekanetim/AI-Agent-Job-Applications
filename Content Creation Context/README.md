# Content Creation Context

The agent records the user's actual publishing voice, audience, topics, public facts, editorial boundaries and media choices in the ignored [profile counterpart](profile.md). The context sets the scope of Autonomous mode. An autonomous post is prepared for publication when the agent verifies it against this context and attaches the result to its board ticket.

Store actual profile values in `profile.local.md`. The agent updates it from the user's instructions. Keep unpublished work on the selected ticket and its private checkpoint. For recurring work, use the shared [task check-in](../automation/scheduling/check-in-prompt.md).
