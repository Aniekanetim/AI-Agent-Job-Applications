# Content creation profile template

Save the actual user's choices in the adjacent ignored `profile.local.md`. The topic strings are the categories the agent uses on tickets. Facts are explicitly public-safe and have stable IDs. The rules cover the user's editorial and publishing boundaries. Media preferences cover permitted sources and acceptable presentation.

```json
{

  "rules": "",
  "mediaPreferences": "",
  "topics": [],
  "facts": []
}
```
