# Application workflow

The [Task Board](../Task%20Board/README.md) says what to do. [Job Context](../Job%20Context/README.md) supplies candidate facts and instructions. This folder explains how to perform the work autonomously.

1. Use [onboarding-workflow.md](onboarding-workflow.md) on first adoption or when a role needs a missing candidate answer. Read supplied CVs, ask relevant follow-ups and save private context automatically; reuse existing answers.
2. Use [application-workflow.md](application-workflow.md) for an email-derived or manual application task.
3. Use [discovery-workflow.md](discovery-workflow.md) when website knowledge is missing or no longer fits the live page.
4. Resume the same task checkpoint after learning or a resolved blocker.

There are no routine review gates or per-application confirmation stages. Ask for a specific missing input only when it prevents progress. Final form inspection and confirmation checks are actions the agent performs, not requests for the user to approve every submission.
